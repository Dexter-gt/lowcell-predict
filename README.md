# LOWCELL Dashboard — full UI prototype
React 18 + Vite + Tailwind 3 + TypeScript. `npm i && npm run dev` (open the printed URL). `npm run build` → `dist/`.

## Structure
- `src/routes.ts` — all 17 sections (matches lowcellpredict.com routes); sidebar, mobile nav and routing read from it. Hash routing (`#markets`).
- `src/pages/` — `Dashboard`, `trade.tsx` (Predictions, Practice, Copy Trade, Wallet, Portfolio, My Copies, Transactions), `research.tsx` (Radar, Analytics, Weather, Risk, Degen Elon, Leaderboard, Rewards), `account.tsx` (Auth, Settings, Methodology).
- `src/components/` — `ui.tsx` primitives, `kit.tsx` (Btn, Table, Drawer, Pills…), `charts.tsx` (SVG, no chart lib), `panels.tsx`, `Shell.tsx`, `TradeTicket.tsx`.
- `src/state/store.tsx` — practice account (cash, positions, copies, ledger, rewards), persisted to localStorage.

## Integration points (the only files to change)
1. **Market data** — `src/data/adapter.ts` + `src/data/extra.ts` implement the interfaces in `src/data/types.ts`. Replace the mock methods with Gamma/CLOB calls (and weather/trader endpoints); keep the returned shapes.
2. **Orders** — `src/integrations/providers.ts` → `trading.placeOrder()` (mode `practice` → `live`). Called by `store.trade()`.
3. **Wallet** — same file → `wallet.connect/disconnect/deposit/withdraw`. Wire to wagmi/viem or similar; `store` already holds `address`.
When going live, also replace the practice-only cash/positions in `store.tsx` with on-chain balances and the user's real positions (see `mark()`), and gate live mode behind `trading.mode`.

## Branding & theming
- Logo: `src/components/Logo.tsx` (generated from `Lowcell_logo.svg`; `<Logo mark />` for the icon only). Wordmark uses `currentColor`, so it flips with the theme.
- Brand colors: violet `#7047FF` → blue `#137FFA` (accent / blue tokens), wordmark `#F6F6F7`.
- Theme: CSS variables in `src/index.css` (`[data-theme=dark|light]`) feed the Tailwind colors in `tailwind.config.js`. `src/hooks/useTheme.ts` handles light / dark / system and persists the choice; an inline script in `index.html` prevents a flash on load. Toggle: top bar sun/moon button and Settings → Appearance.

## Navigation (v3)
- `Predictions` (`#markets`, `src/pages/home.tsx`) is the landing page: category strip, featured markets, all-markets grid. It is reachable from the logo, the header tab, the sidebar, the mobile bottom bar and the Dashboard's "All predictions" button. The header search filters it.
- Header: `src/components/Shell.tsx` → `TopBar` (logo, primary tabs, search, theme, profile). Logo sizes are set where `<Logo className="h-5"/>` is used.

## Predictions catalogue (v4)
- `src/pages/home.tsx` — the Predictions page: source status + refresh, 7 tabs, search/category/status/type filters, grid/list view, live countdowns (`src/hooks/useNow.ts`), LOWCELL spotlight, pagination.
- Pictures: every market has `image` (see `src/data/types.ts`). In production, map it from the Polymarket API image URL; `MarketImage` falls back to an initial tile if it fails to load. The bundled mock pictures are generated by `scripts/make-images.mjs` into `src/assets/images.ts`.
- Markets LOWCELL doesn't model (crypto Up/Down, esports) have `modeled:false`; markets with no prices have `priced:false` (shown as “—”).

## v5: Polymarket-style trading, email login, portfolio
- Market pages: `#market-<id>` (`src/pages/market.tsx`) with chart + range tabs, Yes/No outcome list, order book, rules and a sticky trade panel (`src/components/TradeWidget.tsx`: Buy/Sell, Market/Limit).
- Login: `src/components/AuthModal.tsx` is a Privy-style flow (email -> code -> wallet assigned). Swap `auth` in `src/integrations/providers.ts` for Privy. Trading, copying and the wallet require login.
- Portfolio (`#portfolio`): Positions, Orders (open + limit order history), Closed trades, History. Rewards use "Connect X" (`auth.linkX`).
- Elon markets use the supplied profile picture (`scripts/elon-dp.jpg`). Remember the production image will come from the Polymarket API.

## v6: alignment pass + landmark photos
- Grids size to `minmax(0,1fr)` by default (`index.css`), which fixed sideways overflow on small phones. Audited at 320–1920px: no height mismatches, overlaps or overflow.
- Weather photos are hot-linked from Wikimedia Commons (`src/assets/photos.ts`: Elizabeth Tower, Brooklyn Bridge, Gyeongbokgung). Credits are shown on the Weather page and in How it works. They fall back to bundled illustrations if blocked. For production, download them to `/public/photos` and edit `file`/`photo()`; tweak `focus` to change the crop.

## v7: notifications, collapsible sidebar, smooth theme
- `src/components/Notifications.tsx`: bell with unread badge + panel. Activity (fills, orders, rewards, copies) is stored in `state/store.tsx` (`notifs`, `notifRead`); “Closing soon” and “Edge” alerts are computed live from market data and respect the toggles in Settings. TODO(polymarket): feed fills/resolutions from the user’s websocket.
- Sidebar collapses to an icon rail (header button, state saved in `lowcell.sidebar`).
- Theme switch cross-fades via a short-lived `html.theme-anim` class (see `hooks/useTheme.ts`, `index.css`); disabled for reduced-motion users.

## v8: sidebar header + instant theme
- The logo and collapse toggle now live in the sidebar header (`Sidebar` in `src/components/Shell.tsx`), on the same line as the top bar. Icons sit in one column (x=32px) in both states. Collapsed: logo mark, which swaps to the expand icon on hover/focus. To always show the expand icon instead, remove the `group-hover:opacity-0` classes on the mark.
- Theme switching is instant: `useTheme.ts` pauses transitions for one style recalculation (`html.no-transitions`), so nothing half-fades.
